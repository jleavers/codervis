# agy 1.0.6 Compatibility Implementation Plan

> **Archived — this work was abandoned.** It plans `agy` 1.0.6 support for the Gemini
> Code Assist widget, and that provider was removed from codervis in #13 along with
> Cursor and Copilot. Kept as a record of what was considered, not as work to do: the
> checkbox syntax was removed so no agent picks it up, and nothing here describes code
> that still exists. What environment a command runs in is set once, in
> `.claude/settings.json`; see "The execution context you run in" in `AGENTS.md`.

**Goal:** Make the Gemini Code Assist widget consume `agy` 1.0.6 quota summaries while preserving file-token-only authentication and legacy endpoint compatibility.

**Architecture:** Keep `GeminiLiveQuotaClient` as the single live client. Normalize legacy and summary bucket identities through small parser helpers, then add a summary-first request helper that falls back to `retrieveUserQuota` only for HTTP 404 or 405. Preserve the existing `GeminiLiveQuotaError` boundary and read-only Docker configuration.

**Tech Stack:** Python 3, standard-library `urllib`, pytest, FastAPI application documentation, Docker Compose configuration documentation.

```python
def _request_buckets(payload: dict) -> list[dict]:
    buckets = payload.get("buckets")
    if not isinstance(buckets, list):
        raise GeminiLiveQuotaError("missing buckets array in quota response")

    request_buckets: list[dict] = []
    for bucket in buckets:
        if not isinstance(bucket, dict):
            continue
        token_type = _str_field(bucket, "tokenType", "token_type")
        if token_type and token_type.upper() != "REQUESTS":
            continue
        if _bucket_identity(bucket):
            request_buckets.append(bucket)
    if not request_buckets:
        raise GeminiLiveQuotaError("no request quota buckets in response")
    return request_buckets


def _bucket_identity(bucket: dict) -> str | None:
    values = [
        _model_id(bucket),
        _str_field(bucket, "displayName", "display_name"),
        _str_field(bucket, "bucketId", "bucket_id"),
    ]
    present = [value for value in values if value]
    return " ".join(present) if present else None


def _bucket_detail_name(bucket: dict) -> str | None:
    return (
        _model_id(bucket)
        or _str_field(bucket, "displayName", "display_name")
        or _str_field(bucket, "bucketId", "bucket_id")
    )
```

Update `_bucket_window()` so classification uses `_bucket_identity(bucket)`,
detail output uses `_bucket_detail_name(bucket)`, and tie-breaking priority uses
the combined identity:

```python

...
detail=_detail(detail_name, fraction, bucket),
```

```python
def _fetch_quota(self, token: str, project: str) -> tuple[str, dict]:
    payload = {"project": project}
    try:
        quota = self._post_json(
            RETRIEVE_USER_QUOTA_SUMMARY_METHOD,
            token,
            payload,
        )
        return RETRIEVE_USER_QUOTA_SUMMARY_METHOD, quota
    except _GeminiHTTPError as e:
        if e.code not in {404, 405}:
            raise

    quota = self._post_json(RETRIEVE_USER_QUOTA_METHOD, token, payload)
    return RETRIEVE_USER_QUOTA_METHOD, quota
```
